## 9. Flakiness Risk

| Risk | Source | Mitigation |
|------|--------|-----------|
| bcrypt timing test (#51) | Timing-based assertion may flake on slow CI | Use order-of-magnitude check (both > 50ms) not exact equality |
| sharp dynamic import mock | `vi.mock('sharp')` may not intercept dynamic `import()` | Use `vi.mock()` at top level — vitest hoists mocks before execution |
| File upload in Hono tests | `app.request()` with FormData may need special handling | Use `new FormData()` + `Blob` constructor pattern |
