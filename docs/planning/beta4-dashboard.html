⚡ Recommended Execution Strategy

  1. Design-first — run /cc-design for all 4 waves before any code. Produces ADRs, API contracts, UX wireframes, and data models.
  2. Parallel start — Waves 0 & 1 (password + delete account) are independent. Tackle them simultaneously or sequentially; either way, they don't block anything.
  3. Sequential chain — Wave 2 (notifications) must land before Wave 3 (activity log), since the activity log reuses the event-capture layer from notifications.
  4. Test as you go — each wave has its own test step. Target: 400+ total tests at sprint end.
  5. Review gate — run /cc-review after all 4 waves, then /cc-remediate for any MUST-FIX findings before tagging.
⚠ Design docs required before implementation per project rules. SES production transition needs a cost checkpoint.
