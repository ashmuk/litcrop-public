Rev 8 changes:

  • White farthest ridge removed — m1 is gone. The scene now has 3 mountain layers instead of 4. Sky area above y=70 is empty (breathing room for the tagline).
  • Light blue ridge kept jagged — m2 is now the farthest layer, unchanged from rev 7 (sharp L-command peaks).
  • Brown + sage smoothed — m3 and m4 now use smooth C/S cubic Bezier curves matching the destination-earth-mockup.html style. Thin uniform strokes (1.7 / 1.8). Mixed treatment creates receding-softness depth: sharp far ridge, rolling near ridges — unexpectedly naturalistic.
  • Tagline weight explicit — font-weight="400" added to prevent any OS synthetic-bold inheritance on Brush Script MT. Visual weight is inherent to the brush font, but the font-weight attribute is now unambiguously normal.
  • Draw-in timing shifted — m2 at 0.10s, m3 at 0.35s, m4 at 0.60s (compensates for m1's removal).

What to look at rev 8

Focus your review on (rev 8 changes):
  • Mountain range now 3 layers — blue (jagged, farthest), brown (smooth), sage (smooth, nearest). Does the mixed treatment — sharp distant + rolling near — read naturally, or does it look inconsistent?
  • Empty sky above y=70 — with the white ridge gone, there's ~70px of open cream sky at the top. Too empty? Or does it give the tagline breathing room?
  • Brown + sage smoothness — the new Bezier curves use 4–5 undulations across the width, matching the destination-earth-mockup.html ridge density. Feels right, or do they need more/fewer peaks?
  • Tagline weight — explicit font-weight="400" now set. If it still looks too heavy, the font itself (Brush Script MT) is intrinsically thick — options to try: swap to Apple Chancery (Mac thin script), Lucida Handwriting (Windows), or italic Georgia.
  • Rest unchanged — scenery (trees, farmhouse, crop rows, flow lines), motif wordmark, final brand lockup, wordmark font (Inter 800), scenery dim at reveal — all unchanged.

What's NOT done yet

  • These are PoC artwork — the SVG paths are sketched, not refined. Final art in Step 8 will tighten curves, align letter baselines, and polish spacing.
  • The form fields are decorative — they're not wired to Cognito.
  • i18n (JA) not shown in the mockup, but the real implementation inherits the existing i18n keys.
  • No brand asset export yet (Production scope) — the SVG is still inline, not saved as litcrop-wordmark.svg.
